# 匯出 Xls 範本

系統管理 / 格式匯入（`app/pages/sales-center/system/import-xls-format.vue`）上傳用的 Excel 範本原檔，
匯入後寫進 `CMN_XlsFileFormat`，各功能匯出時套用。原本放在 `D:\開發\Document\專案\業務\`，2026-10-06 搬進版控。

| 檔案 | 功能 | 版型別 |
| --- | --- | --- |
| `出貨檢索-格式.xlsx` | 銷貨檢索 | 有金額權限 |
| `出貨檢索-格式 - 無金額.xlsx` | 銷貨檢索 | 無金額權限 |
| `未完成檢索-格式.xlsx` | 未完成訂單 | 有金額權限 |
| `未完成檢索-不含金額-格式.xlsx` | 未完成訂單 | 無金額權限 |
| `訂單檢核-格式.xlsx` | 訂單資料檢核 | 有金額權限 |

改範本請改這裡的檔案再重新匯入，不要只改 DB。
